CoCo Bakery Grand Opening Invitation
=====================================

Files
- index.html: cover page with Open Invitation button
- invitation.html: details page with interactive controls
- style.css: responsive styling and animated oven-steam effect
- script.js: live countdown and interactions
- cover.png and details.png: supplied artwork, both at ZIP root

Publish on GitHub Pages
1. Extract this ZIP.
2. Upload all files and the assets folder to the root of your GitHub repository.
3. In GitHub, open Settings > Pages and publish from your main branch/root.
4. Open index.html through the GitHub Pages URL.

Important customization before public launch
- The countdown currently targets November 1, 2026 at 10:00 AM Cairo time as a suggested date. Change OPENING_DATE in script.js if needed.
- The map opens a Google Maps search for Dokki, Giza, Egypt. Replace the search URL with the exact shop pin once confirmed.
- RSVP is a front-end demo and does not send responses to the bakery yet. Connect it to a real form/service before launch.
- Offers and photos open working information panels; update them with real offer details and gallery links when available.
